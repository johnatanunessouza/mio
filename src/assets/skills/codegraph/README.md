# using-codegraph

Ensina agentes a usar CodeGraph (índice de símbolos+chamadas de código) como
primeira ferramenta de busca/varredura em qualquer projeto indexado — via MCP
(`codegraph_explore`) e via CLI (`codegraph <comando>`) como fallback e para
comandos sem equivalente MCP (query, node, callers, callees, impact,
affected, files, status, sync).

## Usage

Ver `SKILL.md` pra regra de prioridade e `references/codegraph-tool-contract.md`
pro contrato completo de cada comando.
